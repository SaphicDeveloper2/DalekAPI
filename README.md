# Dalek API – Data-Driven Daleks, Cybermen, and Sonics

This project provides a data-driven system for adding custom Daleks, Cybermen, and Sonic Screwdrivers via datapacks and a small, stable API for modders to plug in behaviors (AI, interactions, and more).

Documentation:
- Datapack author guide: docs/DATA_PACKS.md
- Modding/API guide: docs/MODDING.md

Requirements:
- Java 17
- Forge-based environment
